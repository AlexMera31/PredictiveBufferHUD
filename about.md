# Predictive Buffer HUD
Predictive Input Buffer + menu dentro del juego, estilo Mega Hack, todo en un solo mod.

- **L-Ctrl**: ocultar / mostrar el menu (cambiable).
- **Buffer**: activar / desactivar con click o con tecla (F6 / F7), vehiculo y nivel actual.
- **Ticks**: ticks de buffer por vehiculo con flechas arriba / abajo.
- **Click bufferizado**: ultimo click, total, media e historial.
- **Interfaz**: colores, escala, idioma y teclas.

Ya no hace falta el mod `ai.predictivebuffer`: desinstalalo si lo tienes.
