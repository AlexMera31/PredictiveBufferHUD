# Predictive Buffer HUD
Menu dentro del juego, estilo Mega Hack, para **Predictive Input Buffer**.

- **L-Ctrl**: ocultar / mostrar el menu.
- **Buffer**: activar / desactivar con click, vehiculo y nivel actual.
- **Ticks**: ticks de buffer por vehiculo con flechas arriba / abajo.
- **Click bufferizado**: ultimo click, total, media e historial.
- **Interfaz**: color principal, color gris (rueda de colores) y escala.

Requiere el mod base `ai.predictivebuffer`.
